# VPC MCP Server (Lite)


## Version
v0.1.0

## Overview

VPC MCP Server (Lite) 是一个精简版的 Model Context Protocol 服务器，提供 MCP 客户端（如 Claude Desktop、Cline、Cursor）与华为云 VPC 安全组服务交互的能力。可基于自然语言对安全组及安全组规则进行全链路管理。
